

## Course Dashboard Plan

A clean, RTL (Hebrew) dashboard for an advanced AI course with two sessions, each containing 3 topics. Each topic is a clickable card that navigates to a dedicated page (placeholder for now).

### Layout
- **Header**: Course title at the top
- **Two session cards** side by side (or stacked on mobile):
  - **Session א – AI ככלי (עוזר)**: AI as a Tool
    - 1. השראה – מרעיון לביצוע (Inspiration)
    - 2. פיתוח – פירוק והרכבה (Development)
    - 3. ביצוע – חומר מקצועי (Execution)
  - **Session ב – AI כמחולל (שותף)**: AI as a Generator
    - 1. טבעי – ביומימטיקה (Nature/Biomimicry)
    - 2. לוגי – פונקציונליות (Logical/Functionality)
    - 3. פואטי – תרבות (Poetic/Culture)

### Each topic card shows:
- Topic number, title, and subtitle
- Short description text from the image
- A clickable button/card that navigates to `/session/:sessionId/topic/:topicId`

### Topic pages
- Placeholder pages with the topic title and a "Coming Soon" message, ready for future design

### Design
- RTL direction throughout
- Clean card-based layout with subtle hover effects
- Distinct visual styling for each session (e.g., different accent colors)
- Fully responsive
